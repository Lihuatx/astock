# 项目规范

## 项目目标

构建一个供个人使用的 A 股量化交易可视化面板，覆盖响应式手机与电脑 Web 端。

## 目录约定

- `index.html`：首页总览与页面入口。
- `trade-plan.html`：明日交易计划。
- `account.html`：账户总览。
- `execution.html`：当日执行复盘。
- `research.html`：研究报告库。
- `system.html`：系统运行状态。
- `assets/styles.css`：共享设计令牌、组件与响应式规则。
- `assets/app.js`：共享导航、日期、筛选、抽屉、搜索和异常确认交互。
- `ROADMAP.md`：项目真实进度源。
- `critique.json`：最近一次设计批评结果。

## 实现约束

- 所有用户可见文案使用简体中文，代码标识使用英文。
- 使用符合 A 股交易逻辑的模拟数据，明确标注为模拟数据，不暗示真实收益。
- 每个用户界面页面独立成文件；页面间使用真实产品导航连接。
- 桌面端采用左侧导航，移动端采用顶部摘要与底部导航；不得只是缩小桌面布局。
- 颜色仅通过 `assets/styles.css` 的 `:root` 令牌定义，组件内不写裸色值。
- 金额、比例、时间和证券代码使用等宽数字。
- 所有按钮、筛选、抽屉、搜索和确认操作必须有可用交互及键盘焦点状态。
- 不引入外部依赖，不加载远程字体或图片。
- 每次实现或修复后更新 `ROADMAP.md`，只有已验证内容才能进入“已完成”。

## 验证要求

- 检查 HTML 标签、脚本引用、页面链接和 `data-od-id`。
- 检查 360、390、430、600、768、820、1024、1366、1440、1920 像素宽度下无横向滚动。
- 检查交易日期切换、筛选、详情抽屉、研究搜索、异常确认和日志查看。
- Web Prototype 检查清单的 P0 项必须全部通过。
